# Basic Java Math Programs

This repository contains basic Java programs focusing on loops and conditional statements:
1. **Prime Checker**: Checks whether a given integer is a prime number.
2. **Fibonacci Generator**: Prints the Fibonacci sequence up to a specified number of terms.
